# Avtoon — Корпоративный лендинг (B2B)

Пет-проект: корпоративный лендинг для B2B-сегмента. Реализован как демонстрация навыков фронтенд-разработки.

## Цель проекта

Проект создан для портфолио и демонстрирует следующие навыки:

- Вёрстка по дизайн-макету — пиксельная точность, адаптивность, семантическая разметка
- Next.js App Router — Server Components, разделение серверной и клиентской логики
- TypeScript — строгая типизация компонентов, работа с типами Next.js и React
- Tailwind CSS v4 — дизайн-токены, кастомная тема, адаптивные стили
- SEO — метаданные, Open Graph, robots, sitemap

## Авторство дизайна

Оригинальный дизайн принадлежит компании **[Aston](https://astondevs.ru)**.  
Данный проект является учебной реализацией макета в образовательных целях и не используется в коммерческих целях.  
Все права на дизайн сохраняются за правообладателем.

## Технологии

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript 5**
- **Tailwind CSS v4**

## Начало работы

### Установка зависимостей

```bash
npm install
```

### Переменные окружения

Скопируй `.env.example` в `.env.local` и заполни значения:

```bash
cp .env.example .env.local
```

### Запуск в режиме разработки

```bash
npm run dev
```

Откроется на [http://localhost:3000](http://localhost:3000).

## Команды

| Команда          | Описание                                         |
| ---------------- | ------------------------------------------------ |
| `npm run dev`    | Dev-сервер с Turbopack                           |
| `npm run build`  | Production-сборка                                |
| `npm run start`  | Запуск production-сервера (порт 3010)            |
| `npm run lint`   | Проверка ESLint                                  |
| `npm run check`  | Проверка типов TypeScript                        |
| `npm run format` | Форматирование кода Prettier                     |
| `npm run icons`  | Генерация SVG-компонентов из `src/assets/icons/` |
